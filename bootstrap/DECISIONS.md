# AI·NT — Decision Record Convention

Material architectural or governance decisions should preserve the reasoning and evidence that justified them.

A useful decision record contains:

- context/problem,
- considered alternatives,
- relevant prior art,
- evidence/experiments,
- decision,
- expected benefits,
- cost and complexity introduced,
- security/blast-radius implications,
- reversibility/rollback path,
- conditions that should cause the decision to be revisited.

AINT should increasingly be able to answer **why** a component exists with evidence rather than tradition.
